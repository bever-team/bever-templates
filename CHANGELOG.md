# Changelog

## 0.1.0-prealpha.1

The first public pre-alpha release of the `dotnet-nuxt` template.

- Starter model with projects, tasks, and self-service sign-up.
- A model-driven Nuxt client: sidebar navigation, lists with search, sorting, and paging, detail pages, page, modal, and inline editing, validated forms, searchable reference pickers, sign-in, controls shown by the visitor's roles, a People page where Administrators assign roles, dark mode, and a phone layout.
- The ASP.NET Core server hosts the built client, persists sign-in keys, and limits sign-in attempts.
- A Dockerfile with a `migrate` release step.
- Licensed under MIT No Attribution, so generated projects carry no notice.
